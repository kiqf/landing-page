# The Batman - Página de Destino

Este projeto foi desenvolvido usando HTML e CSS com foco na marcação semântica e responsividade para fornecer uma excelente experiência do usuário em diferentes dispositivos.

## Descrição do Projeto

Esta página de destino visa promover o filme "The Batman", apresentando um breve trailer, os personagens principais, uma sinopse do filme e um link para assistir ao filme. A página é projetada para ser visualmente atraente e fácil de navegar. Este projeto foi desenvolvido com fins estudantis, visando praticar habilidades em HTML e CSS.

## Funcionalidades

- **Trailer**: Um vídeo incorporado do trailer do filme.
- **Personagens**: Uma seção destacando os personagens principais do filme.
- **Sinopse**: Um resumo cativante da trama do filme.
- **Chamada para Ação**: Um botão que direciona os visitantes para uma página onde podem assistir ao filme.

## Destaques do Desenvolvimento

### Semântica

Para garantir que o conteúdo seja bem estruturado e acessível, foram utilizados elementos HTML semânticos, como:

- `<header>`: Contém o título e a navegação principal.
- `<main>`: Envolve o conteúdo principal da página.
- `<article>`: Destinado à sinopse do filme.
- `<footer>`: Inclui informações adicionais e links úteis.

### Responsividade

A página foi desenvolvida com uma abordagem responsiva, utilizando técnicas como:

- **Media Queries**: Ajustes de estilo para diferentes tamanhos de tela, garantindo uma boa apresentação em dispositivos móveis, tablets e desktops.
- **Flexbox e Grid Layout**: Estruturas flexíveis para organizar e alinhar eficientemente os elementos da página.
- **Imagens e Vídeos Responsivos**: Uso de unidades relativas e técnicas de dimensionamento para garantir que imagens e vídeos se ajustem adequadamente a diferentes tamanhos de tela.

## Tecnologias Utilizadas

- **HTML5**: Para estruturar o conteúdo.
- **CSS3**: Para estilização e layout da página.
- **Flexbox e Grid Layout**: Para criar layouts responsivos e flexíveis.
